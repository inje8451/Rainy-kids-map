# ☔ 비쏙맵 BissokMap · ビッソクマップ (인천·부천·김포·서울 실내 나들이)

비 오는 날 아이와 갈 만한 **실내** 명소를 지도·필터로 찾는 정적 웹앱입니다.
한국어/일본어를 즉시 전환할 수 있고, 모든 장소는 공식 홈페이지·공공데이터로 확인한 정보만 실었습니다.
2단계에서 **총 68곳**(기존 31 + 서울 37)으로 늘리고, 화면 전체를 **웜 그레이지 · 코코아 브라운** 톤으로 바꿨습니다.
3단계에서 지도를 OpenStreetMap(Leaflet) 단독에서 **카카오맵 JavaScript SDK + 클러스터러 기본, OSM Leaflet 자동 폴백**으로 전환했습니다.

## 실행

- 라이브: **https://inje8451.github.io/Rainy-kids-map/** (GitHub Pages, `gh-pages` 브랜치 게시)
- 앱 이름: 한국어 **비쏙맵**, 일본어 **ビッソクマップ (BissokMap)**
- `index.html`을 브라우저로 열면 바로 동작합니다(빌드·서버 불필요).
- GitHub Pages 등 아무 정적 호스팅에 폴더째 올려도 됩니다.
- 지도는 **카카오맵 JavaScript SDK**(클러스터러 포함)가 기본입니다. 키는 `5319f5b0184334165a52b3413de7b6d8`이며 카카오 디벨로퍼스에 `https://inje8451.github.io` 도메인이 등록돼 있습니다.
- 카카오 SDK를 못 불러오거나(스크립트 차단·오프라인) 등록되지 않은 도메인에서 타일이 오지 않으면 **Leaflet + OpenStreetMap으로 자동 폴백**합니다(웜 그레이지 필터 + 실패 시 OSM France 자동 전환). 지도가 빈 화면이 되지 않습니다.

```
work/rainy-kids-map/
├─ index.html
├─ assets/styles.css        # 웜 그레이지 · 코코아 브라운 팔레트, 모바일 퍼스트 + 데스크톱 분할
├─ assets/app.js            # 필터·지도(카카오맵/Leaflet 폴백)·모달·한/일 전환
├─ data/places.js           # ★ 데이터 원본 (window.RKM_PLACES)
├─ data/places.json         # 같은 데이터의 JSON 사본
├─ build/                   # 데이터 생성 스크립트 (seoul_a.py · seoul_b.py → build.py)
├─ vendor/leaflet/          # Leaflet 1.9.4 로컬 사본 (폴백용)
├─ shots/                   # 검증 스크린샷 (지도 엔진 전환 후)
├─ verify.py                # Playwright 검증 스크립트 (카카오맵 + 폴백)
└─ verify-report.json       # 검증 결과 원본
```

데이터를 고칠 때는 `build/seoul_a.py`·`seoul_b.py`(서울)와 기존 `data/places.json`(인천·부천·김포)을 수정한 뒤
`python3 build/build.py`를 실행하면 `places.json`과 `places.js`가 함께 갱신됩니다.

## 알아둘 점

- **좌표는 도로명주소·공식 안내 기준 근사 위치**입니다. 상세의 지도 앱 링크는 상호명으로 검색해 정확한 지점을 엽니다.
- 운영시간·요금은 수시로 바뀝니다. 앱 하단과 상세에 "방문 전 공식 안내 확인" 문구를 넣었습니다.
- **국립한글박물관**은 2024-10부터 2028년 하반기까지 새단장 휴관이라 넣지 않았고, **서대문구립 이진아기념도서관**도 리모델링 휴관 중이라 제외했습니다.
- **전쟁기념관 어린이박물관**은 2026-11-24~12-16 새단장 휴관(12-17 재개관 예정)이라 데이터 기준일 현재 '오늘 휴관'으로 표시됩니다.
- 1단계에서 확인이 필요했던 **국립세계문자박물관 '문자 나라 놀이터'**는 2026-11-17부터 개인 예약 없이 입장하는 것으로 공식 안내를 보정했습니다.
- 지도 타일: 카카오맵(© Kakao) 기본, 실패 시 OpenStreetMap 표준 타일(출처 표기, 웜 그레이지 CSS 필터) + OSM France 자동 전환.
  카카오 타일에도 같은 톤의 약한 필터(`grayscale .32 / sepia .14`)를 걸어 배경과 어울리게 했습니다.
- 개인정보(실명·주소·자녀 이름 등)는 코드·문구·메타데이터에 넣지 않았습니다.
